# Projeto 1 – Primeiro Aplicativo

## Descrição

**Objetivo do aplicativo:**
O objetivo deste aplicativo é permitir que o usuário acesse links externos por meio de botões, demonstrando o uso de redirecionamento para páginas na internet dentro de um aplicativo mobile.

**Funcionamento:**
O aplicativo possui botões na interface que, ao serem clicados, direcionam o usuário para um site específico utilizando o navegador do dispositivo.

**Modificações realizadas:**
A interface foi adaptada para representar uma página inicial com informações sobre o filme *Morte em Veneza*. Foram adicionados elementos visuais e textuais relacionados ao filme, mantendo a funcionalidade de redirecionamento por meio de botões.

# Projeto 3 – Terceiro Aplicativo

## Descrição

**Objetivo:**
O objetivo deste aplicativo é permitir que o usuário visualize uma localização específica no mapa, demonstrando o uso de integração com serviços de localização.

**Funcionamento:**
O aplicativo possui um botão que, ao ser clicado, abre o Google Maps direcionando para uma localização previamente definida.

**Modificações realizadas:**
A interface foi adaptada para simular a página inicial de um restaurante italiano. Foram adicionados botões para acesso ao cardápio e à localização, mantendo a funcionalidade principal de abertura do mapa.
